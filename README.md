# 指纹浏览器如何分组和查找环境？

在 **「指纹浏览器」** 里找回一笔订单，最快的线索往往是店名。比如德国店来了一条售后消息，在电脑工作台搜「德国店」，找到正在运行的那一行，点「定位」就能回到原窗口。要让接班同事也找得到，建环境时就把店名和岗位写清楚。[工作台查找教程](https://zwbrowser.com/help/desktop/find-environment/)

![查找窗口前先检查工作台筛选项](https://zwbrowser.com/images/desktop-guide-open-list-light.webp)

## 先用三行样例定下命名规则

| 分组 | 环境名 | 为什么这样写 |
| --- | --- | --- |
| 山海品牌 | 德国店－售后 | 搜地区或岗位都能找到 |
| 山海品牌 | 法国店－运营 | 和德国店区分，同时保留岗位 |
| 内部验收 | 买家－演示站 | 一眼区分演示数据和业务后台 |

在指纹浏览器的桌面工作台，点「环境分组」旁的加号建立项目组。创建环境时，在「基础信息」里填写名称并选分组。保存后先点侧栏的项目名，确认新环境确实归入该组。[环境分组图文说明](https://zwbrowser.com/help/desktop/groups/)

![侧栏中的环境分组入口](https://zwbrowser.com/images/help-workspace-sidebar.webp)

## 为什么昨天的环境今天看不见？

先回到「全部环境」，清除旧的状态和分组筛选，再搜店名中最有辨识度的几个字。若记得窗口已打开，按运行状态缩小范围，找到后点「定位」。从团队收到的项目，还要到「团队环境」检查所属团队。[查找已有环境](https://zwbrowser.com/help/desktop/find-environment/)

整理已有环境时先重命名一小组，让值班同事按新名称完成一次查找。能从订单交接消息里直接提取检索词，再把同一规则推广到其他项目。
